# 仮ナレッジ正本

画面の数字はすべて `src/knowledge/fixtures/` から出す。DOM 直書きしない。

## ファイル対応

| JSON | 内容 | 主な画面 |
|------|------|----------|
| `orders.json` | ネット / FAX / 電話。要確認フラグ | 受注一覧 |
| `pastCases.json` | 類似案件の運賃・付帯作業 | 依頼詳細 |
| `fleet.json` | 保有・車種・空き・乗れる | 依頼詳細の絞り |
| `board.json` | 9/12 のガント初期状態 | 配車盤 |
| `rules.json` | 休息・連続運転・付帯・帰り荷・人員最低件数 | 警告・候補 |

## ルール ID

| ID | 意味 | 画面での扱い |
|----|------|--------------|
| `REST-MIN-09` | 出庫まで休息が9時間を下回る | 確認（止めない） |
| `DRIVE-CONT-04` | 連続運転が4時間を超える | 確認（止めない） |
| `SURCHARGE-FORK` | 積卸ともフォークなのに付帯記載なし、類似の過半で付いていた | 指摘 |
| `RETURN-MATCH` | 空区間と向きが同じ未割当荷物 | 候補 |
| `STAFF-MIN-3` | 当該種別の記録が3件未満 | 人員候補なし |
