## セクション3: さっきの画面で変わったこと

**ラベル**  
さっきの画面で変わったこと

**見出し**  
担当の分け方はそのままです。見る場所だけ一つになります。

**本文**  
- 依頼は入った時点で、一つの表に並びます。  
- 担当は今まで通り分かれています。会議も組織も変えません。  
- 空になった車に、隣の荷物が候補として出ます。  
- 載せる・載せないは担当が押します。休息の確認と、FAXの読み取り漏れは消しません。

**接続文**  
デモで押した「載せる／載せない」が、この候補です。

**変わらないこと**  
- 誰がどの地域を持つか  
- 載せるかの最終判断  
- 休息とFAXの確認  

**変わること**  
- 同じ表を見る  
- 空車の隣に候補が出る  
- 確認は画面に残して人が見る  

### 埋め込み図（part3・3段）

**段1**  
- 見出し: 依頼は、入った時点で1つの表に入ります  
- 本文: 担当の分け方はそのままです。同じ表を見るようになっただけです。  
- 次へ: 荷物を降ろす  

**段2**  
- 見出し: 荷物を降ろすと、その車は現地で空になります  
- 本文: ここまでは前と同じです。  
- 次へ: 隣の荷物が載る  

**段3**  
- 見出し: すぐ下の担当の荷物が、その車に載ります  
- 本文: 空で戻る車が1台減ります。なくなるわけではありません。  
- 次へ: 最初に戻る

## セクション4: 人が増えたとき

**ラベル**  
人が増えたとき

**見出し**  
人が増えると、電話が増えます。表が一つだと、聞く先が減ります。

**本文**  
- 今は5人です。隣が何を持っているかは、聞かなければ分かりません。  
- 仕事が増えると人を足します。足すほど、確認の電話が増えます。  
- 同じ表を見ていれば、聞く先はその表だけです。  
- 担当は増えても構いません。増え方がきついのは、確認の手間のほうです。

**補足**  
5人だと、互いに確認する相手は限られます。20人だと、確認の相手が一気に増えます。数字は説明用です。

- 見出し: いまは、5人がお互いに確認しています

- 次へ: 人が増えると  

**段2**  
- 見出し: 仕事が増えると、人を足して回すことになります  
- 本文: 人が増えるほど、隣に聞く相手が増えます。  
- 次へ: 同じ表を見る  

**段3**  
- 見出し: 全員が同じ表を見ると、確認する先はそこだけになります  
- 本文: 担当は増えます。増え方が変わるのは、確認の手間のほうです。

**図の下の注記**
